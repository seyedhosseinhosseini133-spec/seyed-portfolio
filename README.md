# Seyed Hossein: Personal Portfolio (Next.js 14, React, TypeScript, Tailwind, Framer Motion)
npm install && npm run dev     # development
npm run build && npm start     # production (service worker and install prompt work here, over HTTPS or localhost)
Edit all content in `lib/data.ts`. Put photos/videos in `public/` and reference them as `/name.jpg`.
For best Android/Windows install support, add 192x192 and 512x512 PNG icons to `public/` and list them in `public/manifest.webmanifest`.
